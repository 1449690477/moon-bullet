## 第 1 节 概述与体验目标

### 1.1 一句话定义

以"发射猩红能量球的魔枪"为原型的自机：主炮以 0.55s/发的慢射速发射大颗**穿透腐化光球**；命中敌人施加**腐化标记**，此后该敌人每再受一次腐化系伤害，伤害按 ×2→×4→×8→×16（封顶）递增翻倍；按 `Space` 消耗充能召唤**暗红科技投影分身**（存 3 发充能、同场最多 3 个、各存活 10s），自动锁敌发射小号腐化光球，同样触发并享受翻倍；拾取金色道具进入**暴走形态**（接入现有 `player.berserk` 系统），机体/尾焰/枪口/弹幕整套换装。

### 1.2 玩家体验目标（3 条）

1. **"一发入魂"的顿挫感**：射速慢、单发大、枪口有充能→爆发的两段火光，每一发都像扣了一次扳机，而不是水管式弹幕。
2. **"越打越痛"的滚雪球爽感**：同一目标上连续命中时，翻倍爆发特效和伤害飘字逐级变大变亮，玩家能一眼读出 ×2/×4/×8/×16 的成长。
3. **"虚影军团"的仪式感**：分身以红色全息轮廓实体化登场、半透明噪声抖动待机、数据碎片式消散——它们是投影而非实体，通体暗红、微透、故障感。

**腐化翻倍规则（已确认方案：递增翻倍·封顶）**：

- 敌人对象上挂 `e._cgMark = { n, t }`：`n`=层数，`t`=剩余秒。
- 结算顺序（每次 `cgCorrupt` 弹命中同一敌人）：**先按当前 n 取倍率，再叠层**。倍率 = `min(2^n, 16)`，即 n=0→×1（首次），n=1→×2，n=2→×4，n=3→×8，n≥4→×16 封顶；结算后 `n = min(n+1, 4)`，`t = 6.0` 重置。
- **Boss**：同规则但 `n` 封顶 3（最大 ×8），且照常经过现有 `hitBoss` 的 DPS 信用系统——不得绕开。
- 标记过期：`updateEnemies` 中 `t -= dt`，`t<=0` 时删除 `_cgMark` 并移除标记特效。
- **作用范围**：仅 `s.cgCorrupt===true` 的弹享受倍率（本体+分身）；僚机、插件、其他角色伤害不参与、不叠层。
- 穿透弹对每个敌人只结算一次（沿用现有穿透去重逻辑），单发穿过 N 个敌人则对 N 个敌人各自独立走上述规则。

**挂钩点（精确位置）**：`updatePlayerShots`（第 24567 行）内敌人命中块，第 24814–24815 行现状为：

```js
const actualShotDamage = isDragonBreathShot ? ... : (isSkywardShot(s) ? skywardDamageForHit(s) : s.damage);
e.hp -= actualShotDamage * grindDmg();
```

在 `actualShotDamage` 计算链中插入 `corruptDamageForHit(s, e)`：

```js
function corruptDamageForHit(s, target, isBoss) {
  if (!s.cgCorrupt) return s.damage;
  const st = target._cgMark;
  const mult = st ? Math.min(Math.pow(2, st.n), isBoss ? 8 : 16) : 1;
  const capN = isBoss ? 3 : 4;
  target._cgMark = { n: Math.min((st ? st.n : 0) + 1, capN), t: 6.0 };
  if (st) spawnCgStackBurst(target.x, target.y, mult);   // 翻倍爆发（4.4②）
  else spawnCgMark(target);                               // 首次贴标记
  spawnCgDmgText(target.x, target.y - 18, s.damage * mult, mult); // 分级飘字
  return s.damage * mult;
}
```

Boss 分支：同函数复用于 `updatePlayerShots` 内玩家弹命中 Boss 的块（第 24965 行附近，调用 `hitBoss(...)` 之前），传 `isBoss=true`。

**带标记敌人死亡**：敌人死亡结算处（`updatePlayerShots` 中 `e.hp <= 0` 分支）检查 `e._cgMark && e._cgMark.n >= 1` → 触发 4.4③ 演出（纯演出，无 AOE 伤害；如需伤害后续单独立项）。

```python
def frames_of(img, expect, top_by_area=False):
    a = np.array(img)[:, :, 3] > 20
    lab, n = ndimage.label(ndimage.binary_dilation(a, iterations=18))
    boxes = [(s, (ndimage.sum(a, lab, i + 1))) for i, s in enumerate(ndimage.find_objects(lab))]
    boxes = [b for b in boxes if b[1] > 3000]
    if top_by_area:
        boxes = sorted(boxes, key=lambda b: -b[1])[:expect]
    boxes = sorted(boxes, key=lambda b: (b[0][0].start // (img.size[1] // 3), b[0][1].start))  # 行优先
    assert len(boxes) == expect, f'帧数断言失败: 实测{len(boxes)} 期望{expect}'
    return [b[0] for b in boxes]

def despill_erode(im):
    px = np.array(im).astype(np.int16)
    g_over = px[:, :, 1] > np.maximum(px[:, :, 0], px[:, :, 2])
    px[:, :, 1][g_over] = np.maximum(px[:, :, 0], px[:, :, 2])[g_over]  # despill
    px[:, :, 3][px[:, :, 3] < 8] = 0
    alpha = px[:, :, 3] > 0
    px[:, :, 3][alpha & ~ndimage.binary_erosion(alpha, iterations=1)] = 0  # erode 1px
    return Image.fromarray(px.astype(np.uint8))
# 主流程：逐行切帧→despill_erode→按组统一方形画布（128 倍数）重居中→保存→
# 写 cg_manifest.json{文件:尺寸}→打印汇总表。hue_fix_first2/split_13/make_avatar_cutin/
# dot_rows_rpw 按第 2 节备注实现。
#
# 例外（不走连通域，用固定网格切，防止把一个 cell 内的松散元素错拆/错并）：
#   分身投影噪声粒子(#03)      → 整图 1 帧直出
#   分身用小号弹幕(#07)        → 固定 1行2列（cell 768×1024）
#   暴走翼刃能量延展(#24)      → 固定 2×2（cell 627），左右翼为一体帧，禁止拆成 8 个单翼
#   普通/暴走形态贴图(#17/#21) → 整图 1 帧直出
# 处理顺序注意：#06 帧1-2 的 hue_fix（绿→红色相旋转）必须在 despill 之前执行，
# 否则绿色信号先被 despill 抹掉，色相修复失效。
```

## 运动策略

- [ ] `locked-linear` 航向恒定。
- [ ] `analytic-wave-lane` 只在基准路线法线方向有界摆动。
- [ ] `bezier-lane` 沿固定曲线前进，不累计旋转。
- [ ] `turn-once` 只有一次带预警转向。
- [ ] `brake-hold-release` 减速、停留、释放三段均可读。
- [ ] `orbit-release` 公转阶段稳定，释放后航向不继续旋转。
- [ ] 弹体完全离开可见区后才回收。
- [ ] 尾迹只在发射或转段短暂存在，且无碰撞与伤害。
